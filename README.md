# Abhinav Kumar — Portfolio

My personal developer portfolio, built to showcase who I am, what I know, and what I'm working toward as a Computer Science & Engineering student with a Cyber Security pathway.



## About

I'm a final-year Diploma student in Computer Science & Engineering (Cyber Security pathway) at M.S. Ramaiah Polytechnic, with interests spanning web development, AI, software, hardware, and ethical hacking. This site is where that's documented — honestly, without filler content or fabricated projects.

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- [React](https://react.dev) + [TypeScript](https://www.typescriptlang.org)
- [Tailwind CSS](https://tailwindcss.com)
- [shadcn/ui](https://ui.shadcn.com) components
- [Lucide React](https://lucide.dev) icons

## Project Structure

```
app/                  # Routes (App Router)
components/           # UI components and page sections
  sections/           # Individual portfolio sections (hero, about, skills, etc.)
  ui/                 # Reusable shadcn/ui components
lib/
  site.ts             # Single source of truth for all site content
```

All page content — bio, skills, education, links — lives in `lib/site.ts`. Updating the site's content (e.g. adding a real project once one is finished) means editing that file, not the components.
